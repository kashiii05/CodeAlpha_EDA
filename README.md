# Titanic Exploratory Data Analysis (EDA)

This project was completed as part of the **CodeAlpha Data Analytics Internship**.

## Project Overview

Performed Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Visualizations

* Passenger Survival Count
* Age Distribution
* Gender Distribution
* Survival by Gender
* Passenger Class Distribution
* Fare Distribution
* Age by Passenger Class
* Correlation Heatmap

## Dataset

Titanic Dataset:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

## How to Run

```bash
pip install -r requirements.txt
python eda.py
```

## Output

The project generates multiple PNG charts saved in the project folder.
